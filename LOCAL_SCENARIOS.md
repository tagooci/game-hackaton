# Локальные сценарии 2 и 4

Дополнено: в этой же ветке доступны обновлённый №01 на троих и №05 на четверых. Актуальные роли, финиш проездом в №05 и ограничения модели грузовика описаны в [SCENARIOS_01_05.md](SCENARIOS_01_05.md). Исходная парная карта сохранена, но активный №01 теперь использует `left-turn-v2`.

Интеграционная ветка: `codex/scenarios-integration`, создана от main после `8ba3a69`.

## Как играть

Откройте http://127.0.0.1:5179/ и войдите в аккаунт. Для каждого нового сценария нужны три живых игрока под разными аккаунтами. На одном компьютере используйте отдельные профили браузера: обычные вкладки одного профиля разделяют cookie и один аккаунт отключает прежнее соединение.

- №2, «Равнозначный перекрёсток»: центр X=30, Z=-10. С общего старта двигайтесь по восточной улице к Z=-10, затем поверните на запад к X=30.
- №4, «Круговое движение»: центр X=0, Z=-40. От №2 продолжите на запад по Z=-10 до X=0, затем двигайтесь на юг через наземный проезд под эстакадой к кругу.

Над ближайшей точкой — название и число ожидающих участников. Остановитесь на дороге в зоне: для №2 X=15..45, Z=-25..5; для №4 X=-25..25, Z=-65..-20. Машина должна стоять на нижнем дорожном уровне; верхняя эстакада не считается ожиданием. После остановки троих сервер случайно распределяет три роли, загружает отдельную карту у всех и запускает после готовности.

Задача своей роли указана сверху слева. Правильную очередность интерфейс не подсказывает. Лимит каждого проезда — 90 секунд. У каждого своя финишная арка: остановитесь под ней на секунду. Игрок возвращается в общий мир на свой фактический выезд с сохранением направления. Другие продолжают свой проезд. Повторная запись в тот же сценарий возможна после выезда из его зоны ожидания. После возврата офицер показывает результат. При отключении участника оставшиеся возвращаются к своим входным позициям; при таймауте — также на исходные позиции с соответствующим результатом.

## Что реализовано

№2: поворачивающий с юга налево, движущийся с востока прямо и движущийся с севера прямо. Правила учитывают приоритет справа и встречный поток, разрешают безопасный промежуток, проверяют полосу, направление, полный маршрут и столкновения.

№4: участник с юга идёт на третий западный выезд, участник с запада — на второй восточный, участник на круге — на ближайший северный. Проверяются уступание при въезде, направление по кругу, отклонение от маршрута, полный маршрут и столкновения. На въездах — знаки уступания и кругового движения.

Отдельные сцены экспортированы из реальных модулей большой карты. Большая карта не перезаписывается, модели переиспользуются. Сохранён исходный сценарий left-turn. Его прежняя проверка выделена в legacy_left_turn.py, а очереди и переходы общие.

## Проверки и ограничения

20 автоматических тестов проверяют сцены, хеши ресурсов, кэш-бюджет, дорожное покрытие и бордюры всех опорных траекторий, очереди, роли, готовность всех участников, отключения, таймауты, приоритет, неверное направление, столкновения, защиту от срезания и личные финиши. HTTP/WebSocket-проверки используют отдельную временную базу и три аккаунта; тестируют серверное движение и возврат через правильный выезд. Старый сценарий также проверяется через два соединения.

Приоритет оценивается по геометрическим зонам и прогнозу приближения; это игровая первая версия, не полноценная реконструкция всех ситуаций ПДД. На круге используется порог времени до зоны слияния. Все четыре сцены используют общий PassageResults: события с временными метками, сохранение результата, начисление XP и ИИ-разбор, как в main. №01, №02 и №04 — короткие (90 секунд), №05 — длинный (180 секунд). Разметка не объявлена проверенной: новые сцены проверяют приоритет, маршрут и направление, столкновения. Совместный ручной проезд тремя людьми пока не выполнен.

## Запуск на Windows

Из корня проекта, сервер:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m uvicorn server.app:app --host 127.0.0.1 --port 8000
```

Во втором терминале:

```powershell
cd client
npm run dev -- --host 127.0.0.1
```

Проверки из корня:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s server/tests -v
npm --prefix client run build
```

Для тестов нужны зависимости `server/requirements-dev.txt`. Повторная генерация сцен:

```powershell
.\.venv\Scripts\python.exe -X utf8 client/scripts/prepare-local-scenarios.py
```
