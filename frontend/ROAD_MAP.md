# Предпросмотр дорожной карты

`npm run dev` — открыть карту. WASD перемещает тестовую камеру, Shift ускоряет,
Tab переключает вид сверху / с земли. Узлы мини-карты позволяют переходить между
частями сети. Выпадающий список показывает неподвижный эталон легковой машины
или грузовика для оценки масштаба. Это инструмент автора карты, не физика v2.

Размер сети: 2400 × 2000 м. Модуль — 10 м, проезжая часть — 8 м.
Эталоны: легковая 4.5 × 1.8 × 1.55 м; грузовик 7.2 × 2.5 × 3.2 м.
Габариты являются предложением для согласования с конфигурацией сервера.

## Ресурсы

`public/content/assets/` — локальные оптимизированные Kenney GLB и лицензии CC0.
`public/content/world/chunks/` — пространственные части по 100 м.
`public/content/world/manifest.json` — реестр файлов, SHA-256 и размеры.
`public/content/world/overview.json` — данные общей схемы авторского просмотра.

Пересборка:

```bash
python scripts/prepare-assets.py --roads /путь/kenney_city-kit-roads.zip --cars /путь/kenney_car-kit.zip
npm run generate:roads
```

Для подготовки ассетов нужен Python с Pillow. Во время просмотра Python не нужен.
Палитра перенесена в vertex colors, координаты и нормали квантизованы через
KHR_mesh_quantization. Декодеры CDN и внешние текстуры не используются.
Повторяемая геометрия отрисовывается thin instances.

## Бюджет

Счётчик использует уникальные SHA-256 опубликованных файлов. До каждого fetch
резервируется размер; проверяются длина и SHA. При переходе старые объекты
удаляются, ненужные контейнеры освобождаются, затем загружается новая область.
Cache Storage / IndexedDB не используются; Vite выставляет no-store для /content/.
В production такие же заголовки должен выставлять сервер ресурсов.

Минимальный текущий участок обязателен, соседние части добавляются в пределах
бюджета. Часть карты может быть невидима за границей готовой области. Камера —
инструмент проверки, не машина; ограничение автомобильного движения по готовой
области остаётся ответственностью сервера согласно v2.

## Граница текущей реализации

Это дорожный каркас и локальный загрузчик для проверки масштаба и ресурсов.
Существующий /ws не изменён; игровой клиент v2 не подключён.
Схема JSON карты — рабочий черновик, не новая версия сетевого протокола.
Для серверной интеграции ещё требуется связать полосы через перекрёстки,
заполнить laneIds у знаков/стоп-линий и конфликтные маршруты.
Два круга пока используют один модуль Kenney; отдельная двухполосная разметка,
полосы разгона/замедления, сужения, направляющие стрелки и зоны сценариев ещё
не завершены. Светофоры пока статические и не показывают фазы snapshot.
