# Дорожный помощник: отображение в сценарии

Ветка: feature/scenario-assistant-ui.

Обычный запуск — по README. После загрузки сценария left-turn робот показывает задачу своей роли. Когда snapshot содержит scenarioResult, окно показывает точную строку сервера. Реплику можно свернуть и открыть нажатием на персонажа. Длинная реплика разбита на страницы. До закрытия окна клиент отправляет тормоз, курсор освобождён для кнопок. После закрытия нажмите на сцену для управления.

Быстрый просмотр без сервера и второго игрока: запустите клиент npm run dev и откройте http://localhost:5179/?assistant-preview=1. Вверху переключатели начала сценария, успешного проезда и нарушения. Данные этого режима — примеры, фон схематический.

Персонаж — исходный вектор public/assistant/robot.svg. Компонент src/assistant/scenarioAssistant.ts, стили src/assistant/assistant.css. Будущий ИИ сможет поставлять текст для этого компонента; сейчас оценки и реплики не генерируются моделью. Серверный протокол и сценарная логика не меняются.
