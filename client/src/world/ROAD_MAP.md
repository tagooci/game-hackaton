# Карта в игровом клиенте

Основа загрузчика перенесена из `origin/frontend`, коммит `579ca27`.
Текущая карта генерируется `client/scripts/generate-road-map.mjs`.
Дорожная сеть: около 410 × 370 м, 502 плитки Kenney, 46 перекрёстков.
Мост, короткий тоннель, 5 железнодорожных переездов и 3 остановки.
Железная дорога проходит поперёк дорог; поезда и дома не добавлены.
На переездах шпалы заканчиваются у асфальта, рельсы утоплены в покрытие.
Все дороги замкнуты и достижимы; мост и проезд под ним — разные уровни.
Повороты и Т-перекрёстки проверяются по реальным проёмам GLB, а не только по графу.

Вход и управление остаются игровыми: HTTP-авторизация, `/ws/v2`, Python-физика.
В scene_prepare сервер передаёт `plan.mapManifestUrl`. Клиент ждёт загрузки
первой области до scene_ready, затем обновляет область по положению машины.
Подгрузка идёт в фоне: старая дорога остаётся видимой, общие meshes сохраняются.
Новые шейдеры готовятся заранее; матрицы объектов переключаются одним шагом.
Участки имеют размер 20 м. Полный круг загрузки — 65 м вокруг машины,
план пересчитывается каждые 2,5 м. До запроса освобождаются только участки
за этим кругом. Дальность тумана 40 м и камеры не более 12 м скрывают границу.
Ближние участки не пропускаются ради экономии бюджета: при нехватке выдаётся ошибка.
Старые ресурсы освобождаются после переключения, а бюджет включает одновременно
старые, подготовленные и ещё загружаемые файлы. Обычная подгрузка не включает тормоз.
При ошибке текущая дорога сохраняется и показывается сообщение. После выхода загрузчик
освобождает модели, включая запросы, завершившиеся после удаления сцены.

Начальная позиция берётся из spawn манифеста. Сохранённая позиция переносится
на старт только при смене worldId. Python вычисляет высоту и наклон по дорожным
поверхностям из navigation.json. В БД сохраняются координаты, уровень и worldId:
после переподключения машина на мосту не попадает на проезд под ним.

## Ограничения

Загрузчик дорог считает уникальные размеры опубликованных файлов, проверяет
размер и SHA-256; его бюджет — `floor(manifest.worldBytes / 10)` (сейчас 52696 байт). Заголовок no-store выставляется
в Vite и FastAPI. Это бюджет только карты: исходная модель игровой машины,
текстура и метаданные манифеста находятся вне этого счётчика. Поэтому общий
лимит клиента 10% пока не обеспечен. RAM/VRAM также не равны размерам файлов.

Высота дорог учитывается, но нет коллизий со стенами, проверки ПДД, работающих фаз светофоров
и серверного запрета выезда за загруженную область. Планы участков выбирает
клиент; полноценное управление контентом сервером остаётся отдельным этапом.

Авторский интерфейс предпросмотра и его управление камерой в игру не перенесены.
Генераторы находятся в `client/scripts/`. Для изменения схемы достаточно
поправить пути в generate-road-map.mjs и выполнить `node client/scripts/generate-road-map.mjs`.
Перезапустите Python-сервер: он читает поверхности при запуске.
Пересборка ассетов (готовые GLB уже в репозитории) требует Pillow из
`client/scripts/requirements-assets.txt` и локальных ZIP Kenney:

```sh
.venv/bin/python client/scripts/prepare-road-assets.py --roads /path/kenney_city-kit-roads.zip --rail /path/kenney_train-kit.zip --markings
.venv/bin/python client/scripts/build-road-props.py
node client/scripts/generate-road-map.mjs
```

## Проверка загрузки и кэша

В режиме разработки (порт 5179), после входа в игру:

1. Откройте DevTools → Network, включите Preserve log и фильтр `/content/`.
   Начальная загрузка покажет manifest.json, overview.json, JSON участков и GLB.
   При езде появляются запросы только недостающих ресурсов. У ответов no-store.
2. В Console выполните `window.roadCache` или
   `console.table(window.roadCache.resources)`. Это снимок внутреннего кэша
   приложения: IDs и размеры находящихся сейчас в памяти файлов.
3. Для наблюдения во время езды:

```js
window.cacheWatch = setInterval(() => {
  const c = window.roadCache;
  if (!c) return;
  console.log({
    chunk: c.chunk, next: c.requestedChunk,
    used: c.activeBytes, reserved: c.reservedBytes, budget: c.budgetBytes,
    fits: c.activeBytes + c.reservedBytes <= c.budgetBytes
  });
}, 1000);
```

Остановка: `clearInterval(window.cacheWatch)`.
Поле chunk показывает ячейку плана с шагом 2,5 м; IDs файлов перечислены в resources.
При переходе reservedBytes временно увеличивается, chunk меняется после готовности.
После проезда ненужные IDs исчезают из resources. Значение fits должно быть true.
Network хранит историю запросов: её суммарный объём не равен текущему кэшу.
В Application → Cache Storage эти данные не появятся: это кэш приложения в памяти,
а не постоянный браузерный кэш. Счётчик показывает размеры файлов, не расход RAM/VRAM.
