# Миникарта

Обычный JS-компонент `minimap.js`. `track.svg` — векторный исходник; в игре загружается только его заранее подготовленная lossless-копия `track.webp` размером 560×560. SVG не загружается и не отрисовывается во время игры.

Фон — отдельный статичный bitmap-слой. Точки — маленький прозрачный canvas 320×320. Обновление вызывается только из серверных snapshot, максимум около 10 раз/с; в игровом render loop работы миникарты нет. Координаты хранятся в переиспользуемом типизированном буфере. При неподвижных машинах перерисовки нет. При скрытии вкладки обновления пропускаются. WebSocket, requestAnimationFrame и таймеров собственного цикла у миникарты нет.

Свою точку выделяет кольцо и направление. Цвета соответствуют пяти цветам кузова; отключившиеся игроки исчезают из нового snapshot.

Генерация из корня проекта после изменения трассы:

```sh
python -m pip install shapely cairosvg Pillow
python client/scripts/generate-minimap.py
```

Генератор создаёт и SVG-исходник, и WebP. Второй Babylon-сцены и служебного HTML-просмотрщика в проекте нет.
