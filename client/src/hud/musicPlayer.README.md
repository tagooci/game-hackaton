# Музыкальный плеер

JS-компонент `musicPlayer.js`. Плейлист в `musicPlaylist.js`; MP3 лежат в `client/public/music/`. У каждого экземпляра свой HTMLAudioElement, состояние, обработчики и копия плейлиста. На сервер состояние не передаётся, между игроками и вкладками не синхронизируется.

Музыка включается по первому клику или нажатию клавиши в игре либо кнопкой воспроизведения. Предыдущий/следующий переключают треки по кругу, пауза сохраняется при ручном переключении. По окончании трека автоматически начинается следующий. Громкость по умолчанию 35%. `preload=none` не загружает весь плейлист заранее; таймеров и циклов отрисовки нет.

`setTracks(tracks)` меняет список и переводит плеер на паузу, `getState()` возвращает текущее состояние. При действиях отправляется локальное событие `music-player-change`. `dispose()` останавливает звук, освобождает текущий аудиоресурс и обработчики при выходе из игры.

Названия в интерфейсе: dealer.mp3 — «Vigorous», tarck2.mp3 — «Funny», treck3.mp3 — «Light».
